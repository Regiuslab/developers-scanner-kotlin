# Инструкция складу: контролируемое тестирование ТСД 1.1.0

Версия на экране «О приложении» / в установщике: **1.1.0** (`versionCode 2`).  
Режим: обычная работа с Битрикс (**не** серверные блокировки). Проводить документы пачкой или с двух ТСД сразу **нельзя**.

## Установка

1. **Не удалять** текущее приложение «Склад».
2. Поставить `tsd-1.1.0-release.apk` поверх установленной версии.
3. Если система просит удалить старое из‑за подписи — **не соглашаться**, вызвать разработчика.
4. После установки открыть незавершённый приход (если он был): позиции должны остаться.

## Этап А — без проведения

Цель: убедиться, что сканы не теряются. Кнопку **«Провести» не нажимать**.

1. Войти по PIN, открыть черновик прихода (или создать новый, но не проводить).
2. Отсканировать **50–100** товаров лазерным сканером. После каждых ~20 позиций глянуть, что список на месте.
3. Выйти из приложения и открыть снова — список тот же.
4. Перезагрузить ТСД кнопкой питания. Снова открыть тот же документ — список тот же.
5. Выключить Wi‑Fi / мобильную сеть, добавить 2–3 скана, включить сеть. Список на месте, ошибки сети не должны стереть черновик.
6. Записать: номер документа, число позиций, время, ФИО. Если позиции пропали — **стоп**, фото экрана, не сканировать заново «с нуля».

## Если приложение упало или ТСД выключился

1. Включить устройство, открыть «Склад», тот же приход.
2. Не создавать второй документ на ту же поставку.
3. Сверить число строк с черновиком/накладной.
4. При расхождении — остановиться и передать лог/скрин разработчику.

## Этап Б — одно контрольное проведение

Только после команды ответственного и **после** проверки серверного модуля на staging. На бою — **один** заранее названный документ, склад и номенклатура.

1. Зафиксировать остаток выбранной номенклатуры на складе **до**.
2. Провести только этот документ с ТСД.
3. Сверить остаток **после** (ожидаемый прирост = сумма количеств документа).
4. Если остаток вырос сильнее, документ проведён дважды, или Битрикс вернул ошибку сверки — **стоп**, не повторять «Провести».

Не делать: два ТСД на один документ, 10 тестовых проведений, чужие склады, «попробовать ещё раз» при сомнении в результате.

## Когда звать разработчика

- Пропали сканы после перезапуска.
- Установщик требует удалить приложение.
- Сообщение про неизвестный статус документа, сверку, конфликт штрихкода.
- Остатки в Битрикс не совпали с документом.
