## Что уже сделано в коде (сборка для клиента)

- Двойной тап «Добавить»: `InFlightGuard` + `AtomicBoolean` в сервисе; кнопка держится ~1 с и до перезагрузки списка.  
- Id склада: `BitrixNumberParser` (`1` / `1.0` / `"1"`), тесты `StoreMapper`.  
- Скан, пока грузится документ: `MovingDocumentStateMerger`.  
- Нет ложного «Доступно: 7.87» из `product.quantity`; без складов текст «Склады не загрузились» + алерт.  
- Повтор «Провести»: не `element.add` для строк, у которых уже есть id (`MovingConductRetrySync`).  
- `catalog.document.conduct` — **POST** `{ id }`; разбор `Unknown API error` (`BitrixApiErrorParser`).  
- Приход: карточка в `NestedScrollView`; списки прихода **и** перемещения — новые сверху (`DocumentListNewestFirst`).  
- README, `GAPS.md`.  

Debug APK (на момент сессии): `dist/Sklad-debug-2026-08-27.apk` (папка `dist/` в git **не** лежит) или `app/build/outputs/apk/debug/app-debug.apk`. Перед установкой на ТСД удалить старое «Склад».

Эмулятор: AVD `Pixel_10_Pro_XL`. Скан без broadcast железа не проверить.
